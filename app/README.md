# Aplicación web de demostración

Aplicación que se conecta a la base de datos alojada en la máquina virtual y expone la consulta del catálogo y la disponibilidad del inventario.

Pendiente de definir el stack tecnológico.

> La cadena de conexión y las credenciales no se versionan. Usar un archivo `.env` local a partir de un `.env.example`.
